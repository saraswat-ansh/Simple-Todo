# 📝 To-Do List

A simple and responsive To-Do List web application built with **HTML, CSS, and JavaScript**.

The app allows users to create, complete, edit, and delete tasks, with tasks automatically saved in the browser using **localStorage**.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* ✏️ Edit tasks by double-clicking them
* 🗑️ Delete tasks
* 💾 Automatically saves tasks using localStorage
* ⌨️ Press **Enter** to add a task
* 📱 Responsive design
* 🎨 Gradient UI with hover and fade-in effects

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling, animations, and responsive design
* **JavaScript** – DOM manipulation and task functionality
* **LocalStorage** – Persistent task storage
